# MyCra

ブラウザで遊べる Minecraft 風ボクセルワールドです。Three.js と Vite で作られており、GitHub Actions で GitHub Pages へ自動デプロイされます。

**公開 URL:** https://isamutakiguchi.github.io/mycra/

## 遊び方

操作は Minecraft (Java 版 / Bedrock 版) と同じです。

### PC (キーボード・マウス)

| 操作 | キー |
| --- | --- |
| 移動 | `W` `A` `S` `D` |
| 視点 | マウス |
| ジャンプ | `Space` |
| スニーク | `Shift` (足場の端から落ちない・作業台を開かずにブロックを置ける) |
| ダッシュ | `Ctrl` または `W` 二度押し |
| 壊す / 攻撃 | 左クリック (長押しで掘る) |
| 置く / 使う / 食べる | 右クリック (食べ物は長押し) |
| ブロック選択 | ホイールクリック |
| 捨てる | `Q` (`Ctrl` + `Q` でスタックごと) |
| 持ち物・クラフト | `E` |
| ホットバー | `1`〜`9` / マウスホイール |
| 視点切替 | `F5` |
| デバッグ表示 | `F3` |
| HUD 表示切替 | `F1` |
| 飛行 (クリエイティブ) | `Space` 二度押し (`Space` 上昇 / `Shift` 下降) |
| メニュー | `Esc` |

### タブレット / スマートフォン

タッチ操作に自動で切り替わります。

| 操作 | 方法 |
| --- | --- |
| 移動 | 画面左側をなぞる (仮想ジョイスティック。外側までなぞるとダッシュ) |
| 視点 | 画面右側をなぞる |
| 置く / 使う / 攻撃 | ブロックをタップ (指の位置が対象) |
| 壊す | ブロックを長押し (指の下のブロックを掘り続ける) |
| ジャンプ | ▲ (クリエイティブでは二度押しで飛行) |
| スニーク | ⇩ で切替 (飛行中は下降) |
| 持ち物・クラフト | 右上の ⋯ |
| ホットバー | 下のバーをタップ |
| メニュー | 右上の ☰ |

## 要素

- **ワールド**: 128×128×64 ブロック。草原・山・砂浜・海・雪山・森に加えて、洞窟と石炭・鉄の鉱脈があります。
- **ゲームモード** (メニューで切替): サバイバル (体力・満腹度・落下ダメージ・道具が必要)、クリエイティブ (無限のアイテム・飛行・即時破壊)、アドベンチャー (ブロックの破壊と設置ができない)、スペクテイター (壁をすり抜けて飛び回り、何にも触れず、モブにも狙われない)。
- **難易度** (メニューで切替): ピースフル (敵がわかず、満腹度が減らず、体力が回復し続ける)、イージー (敵のダメージ半分、飢えは体力 5 個分まで)、ノーマル (飢えは体力半個分まで)、ハード (敵のダメージ 1.5 倍、敵が多く、飢えで死ぬ)。
- **ブロック**: 草・土・石・丸石・砂・砂利・原木・木材・葉・ガラス・レンガ・雪・羊毛・たいまつ・作業台・かまど・石炭鉱石・鉄鉱石・岩盤。ブロックごとに硬さと適正道具があり、石や鉱石はツルハシがないとドロップしません。
- **道具**: 木・石・鉄のツルハシ・斧・シャベル・剣。段階が上がるほど速く掘れ、攻撃力も上がります。
- **クラフト**: `E` で開くクラフト画面にレシピが並びます。作業台やかまどが近く (4 ブロック以内) にあると、道具や精錬 (鉄インゴット・料理・ガラス) のレシピが使えます。
- **たいまつ**: 光源として周囲を照らします。空の光と光源の光を Minecraft と同じ方式で伝播させているので、洞窟や夜は暗く、たいまつを置くと明るくなります。
- **動物**: ブタ・ウシ・ヒツジ・ニワトリ。倒すと肉や羊毛・羽根を落とし、かまどで焼くと満腹度が多く回復します。
- **敵**: 夜や暗い場所にゾンビ・スケルトン (矢を撃つ)・クリーパー (近づくと爆発してブロックを壊す) がわきます。ゾンビとスケルトンは日光で燃えます。
- **一人称の腕**: 画面右下に腕と持ち物が表示され、操作に合わせて振ります。`F5` で三人称視点になります。
- **昼夜**: 20 分で 1 日が経過します。
- **ホーム画面に追加**: Web アプリマニフェストとアイコン (`public/icons/`) を同梱しているので、iPhone / iPad の Safari や Android の Chrome で「ホーム画面に追加」すると草ブロックのロゴ付きで全画面起動します。
- **セーブ**: ブロックの変更・持ち物・体力・モブ・落ちているアイテム・時刻をブラウザの `localStorage` に自動セーブします (10 秒ごと・メニューを開いたとき)。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
npm run preview  # ビルド結果を確認
```

## デプロイ

`.github/workflows/deploy.yml` が以下を自動で行います。

1. すべてのブランチ・Pull Request で `npm ci && npm run build` を実行してビルドを検証
2. `main` ブランチへの push 時のみ、`dist/` を `gh-pages` ブランチへ push して GitHub Pages で公開

`gh-pages` ブランチが作られると GitHub Pages が自動で有効になります。もし公開されない場合は、リポジトリの **Settings → Pages → Build and deployment → Source** を **Deploy from a branch**、Branch を **gh-pages** / **/(root)** に設定してください。

## 構成

```
index.html          画面・メニュー
src/main.js         起動、入力 (Minecraft 準拠)、採掘・設置・攻撃・食事、セーブ、昼夜、メインループ
src/world.js        地形生成 (洞窟・鉱脈)、チャンクのメッシュ化 (面カリング・AO・頂点ライト)、たいまつモデル
src/lighting.js     空の光と光源の光の伝播 (Minecraft 方式)
src/blocks.js       ブロックの定義 (硬さ・適正道具・ドロップ)、Canvas で生成するテクスチャアトラス
src/items.js        アイテム・道具・食べ物の定義、ドット絵、レシピ
src/inventory.js    持ち物 (36 スロット) とスタック操作、クラフト
src/ui.js           インベントリ / クラフト / クリエイティブカタログ画面
src/hud.js          体力・満腹度・ホットバーなどの HUD
src/player.js       プレイヤー: 移動・スニーク・ダッシュ・飛行・体力・満腹度・落下ダメージ
src/physics.js      AABB の移動と衝突 (プレイヤー・モブ・アイテム共通)
src/mobs.js         動物と敵の AI・スポーン・矢・爆発
src/models.js       ブロック風のモブ / プレイヤーモデル
src/drops.js        落ちているアイテムと拾得
src/hand.js         画面手前に描く一人称の腕と持ち物 (振り・持ち替えアニメーション)
src/touch.js        タブレット向けタッチ操作 (仮想ジョイスティック・ボタン)
src/raycast.js      視線が当たるブロックを求めるボクセル DDA
src/noise.js        シード付き乱数、2D パーリンノイズ
```
