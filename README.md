# MyCra

ブラウザで遊べる Minecraft 風ボクセルワールドです。Three.js と Vite で作られており、GitHub Actions で GitHub Pages へ自動デプロイされます。

**公開 URL:** https://isamutakiguchi.github.io/mycra/

## 遊び方

操作は Minecraft (Java 版 / Bedrock 版) と同じです。

### PC (キーボード・マウス)

| 操作 | キー |
| --- | --- |
| 移動 | `W` `A` `S` `D` |
| 視点 | マウス |
| ジャンプ | `Space` |
| スニーク | `Shift` (足場の端から落ちない・作業台を開かずにブロックを置ける) |
| ダッシュ | `Ctrl` または `W` 二度押し |
| 壊す / 攻撃 | 左クリック (長押しで掘る) |
| 置く / 使う / 食べる | 右クリック (ドア・ベッド・チェストを使う、防具を着る、食べ物は長押し、弓は長押しで引く) |
| ブロック選択 | ホイールクリック |
| 捨てる | `Q` (`Ctrl` + `Q` でスタックごと) |
| 持ち物・クラフト | `E` |
| ホットバー | `1`〜`9` / マウスホイール |
| 視点切替 | `F5` |
| デバッグ表示 | `F3` |
| HUD 表示切替 | `F1` |
| 飛行 (クリエイティブ) | `Space` 二度押し (`Space` 上昇 / `Shift` 下降) |
| チャット (マルチプレイ中) | `T` (`Enter` で送信) |
| メニュー | `Esc` |

### タブレット / スマートフォン

タッチ操作に自動で切り替わります。

| 操作 | 方法 |
| --- | --- |
| 移動 | 画面左側をなぞる (仮想ジョイスティック。外側までなぞるとダッシュ) |
| 視点 | 画面右側をなぞる |
| 置く / 使う / 攻撃 | ブロックをタップ (指の位置が対象。ドアの開閉やチェストもタップ。弓はタップで射る) |
| 壊す | ブロックを長押し (指の下のブロックを掘り続ける) |
| ジャンプ | ▲ (クリエイティブでは二度押しで飛行) |
| スニーク | ⇩ で切替 (飛行中は下降) |
| 持ち物・クラフト | 右上の ⋯ |
| チャット (マルチプレイ中) | 右上の 💬 |
| ホットバー | 下のバーをタップ |
| メニュー | 右上の ☰ |

### みんなで遊ぶ (マルチプレイ)

サーバーを用意しなくても、ブラウザ同士を直接つないで同じ世界で遊べます。

1. 遊ぶ人の一人 (ホスト) が、メニューの「マルチプレイ」で名前を入れて **この世界を公開する** を押します。6 文字の **ルームコード** が表示されます。
2. **招待リンクをコピー** して友だちに送るか、ルームコードを伝えます。
3. 友だちは招待リンクを開くか、メニューにルームコードを入れて **参加する** を押します。ホストの世界に入ります。

- ブロックの変更・プレイヤーの動き・モブ・落ちているアイテム・チェストの中身・時刻・難易度が全員で同期します。ほかのプレイヤーは名札付きで表示されます。
- ほかのプレイヤーを攻撃できます (PvP)。夜は全員がベッドで眠ると朝になります。
- 世界はホストのブラウザに保存されます。参加者の持ち物と位置もホストの世界に保存され、次に参加したときに引き継がれます (参加者自身の世界は別に残ります)。
- ゲームモードは各自で選べます。難易度はホストが決めます。
- 注意: ホストがページを閉じると、全員が切断されます (参加者は自分の世界に戻ります)。ホストはタブを開いたままにしてください。
- 接続の仲介には PeerJS の公開サーバーを使い、ゲームのデータはブラウザ同士 (WebRTC) で直接やりとりします。会社や学校のネットワークなど、環境によってはつながらないことがあります。

## 要素

- **アイテム**: 744 種類 (ブロック 586 種、道具・防具・食料・素材など 158 種)。クラフトのレシピは 609 種 (うち精錬 65 種)。
  - 木材 11 種 (オーク、トウヒ、シラカバ、ジャングル、アカシア、ダークオーク、マングローブ、サクラ、竹、真紅、歪んだ) ごとに原木・板材・ハーフブロック・階段・フェンス・フェンスゲート・ドア・トラップドア・感圧板・ボタン・葉・苗木
  - 石材 (石、丸石、石レンガ、花崗岩、閃緑岩、安山岩、深層岩、凝灰岩、砂岩、プリズマリン、ネザーレンガ、ブラックストーン、エンドストーン、プルパー、クォーツ、銅など) とそのハーフブロック・階段・塀
  - 16 色の羊毛・カーペット・コンクリート・コンクリートパウダー・テラコッタ・彩釉テラコッタ・色付きガラス・色付きガラス板・ベッド・染料
  - 鉱石 (石炭・鉄・銅・金・レッドストーン・エメラルド・ラピスラズリ・ダイヤモンド、深層岩版、ネザー金・ネザークォーツ・古代の残骸) と鉱物ブロック
  - 木・石・鉄・金・ダイヤモンド・ネザライトの剣・ツルハシ・斧・シャベル・クワ、革・チェーン・鉄・金・ダイヤモンド・ネザライトの防具
  - 弓と矢、バケツ、ハサミ、火打石と打ち金、コンパス、時計、釣り竿、肉・魚・パン・シチューなどの食料
- **形と機能のあるブロック**
  - ドア・トラップドア・フェンスゲートは右クリック (タップ) で開閉します。ドアは 2 マス分で、隣に置くと両開きになります。
  - ハーフブロックは上下に置き分けられ、同じものを重ねると 1 ブロックになります。階段は向きと上下を持ちます。
  - フェンス・塀・板ガラス・鉄格子は隣と自動でつながります。
  - 高さ 0.6 までの段差 (ハーフブロック・階段) は歩くだけで上れます。はしごは押し当てて前進すると登れ、スニークで止まれます。
  - ベッドは夜に使うと朝まで眠れ、リスポーン地点になります。チェストと樽には 27 個まで物を入れられます。
  - TNT は火打石と打ち金で着火すると 4 秒後に爆発し、近くの TNT も誘爆します。
  - 骨粉を苗木に使うと木が育ちます (時間でも育ちます)。ハサミをカボチャに使うと、くり抜かれたカボチャになります。
  - コンクリートパウダーは水に触れるとコンクリートになります。バケツで水をくむ・置くことができます。
  - 氷の上は滑り、スライムブロックでは跳ね、干草の俵やベッドは落下ダメージを減らし、サボテンやマグマブロックは触れるとダメージを受けます。
- **道具と防具**: Minecraft と同じ式で採掘時間が決まり、道具ごとに耐久値があります (ホットバーにゲージを表示)。鉱石は必要な段階のツルハシでないとドロップしません (鉄は石以上、ダイヤは鉄以上、黒曜石はダイヤ以上)。防具は右クリックか持ち物画面の防具欄で装備し、防御ポイントに応じてダメージが減ります。
- **クラフト**: `E` の画面にレシピが並びます (検索と「作れるものだけ表示」の切替付き)。4 個を超える素材を使うものや 3 列が必要なものは作業台、精錬はかまど (燻製器・溶鉱炉でも可) と燃料、ネザライトへの強化は鍛冶台が近くに必要です。
- **クリエイティブ**: 持ち物画面が Minecraft と同じタブ (建築ブロック・色付きブロック・天然ブロック・機能ブロック・道具・戦闘・食料・材料) と検索になります。
- **ワールド**: 128×128×64 ブロック。草原・山・砂浜・海・雪山と、オーク・シラカバ・トウヒ・サクラの森があり、草花・キノコ・カボチャ・サトウキビが生えます。地下は洞窟と深層岩で、8 種類の鉱石が高さに応じて埋まっています。
- **ゲームモード** (メニューで切替): サバイバル (体力・満腹度・落下ダメージ・道具が必要)、クリエイティブ (無限のアイテム・飛行・即時破壊)、アドベンチャー (ブロックの破壊と設置ができない)、スペクテイター (壁をすり抜けて飛び回り、何にも触れず、モブにも狙われない)。
- **難易度** (メニューで切替): ピースフル (敵がわかず、満腹度が減らず、体力が回復し続ける)、イージー (敵のダメージ半分、飢えは体力 5 個分まで)、ノーマル (飢えは体力半個分まで)、ハード (敵のダメージ 1.5 倍、敵が多く、飢えで死ぬ)。
- **松明**: 光源として周囲を照らします。空の光と光源の光を Minecraft と同じ方式で伝播させているので、洞窟や夜は暗く、松明やランタンを置くと明るくなります。
- **動物**: ブタ・ウシ・ヒツジ・ニワトリ。倒すと肉や革・羊毛・羽根を落とし、かまどで焼くと満腹度が多く回復します。
- **敵**: 夜や暗い場所にゾンビ・スケルトン (矢を撃つ)・クリーパー (近づくと爆発してブロックを壊す) がわきます。ゾンビとスケルトンは日光で燃え、腐った肉・骨・矢・火薬を落とします。
- **一人称の腕**: 画面右下に腕と持ち物が表示され、操作に合わせて振ります。`F5` で三人称視点になります。
- **昼夜**: 20 分で 1 日が経過します。
- **セーブ**: ブロックの変更と向き・持ち物と防具・チェストの中身・体力・モブ・落ちているアイテム・時刻をブラウザの `localStorage` に自動セーブします (10 秒ごと・メニューを開いたとき)。以前のバージョンのセーブもそのまま読み込めます。
- **ホーム画面に追加**: Web アプリマニフェストとアイコン (`public/icons/`) を同梱しているので、iPhone / iPad の Safari や Android の Chrome で「ホーム画面に追加」すると草ブロックのロゴ付きで全画面起動します。

### Minecraft との違い

Minecraft Java 版には約 1,400 種類のアイテムがありますが、次のものは入っていません。

- スポーンエッグ、レコード、旗の模様、ポーションやエンチャントの本などの派生アイテム
- レッドストーン回路の部品 (リピーター、ピストン、ホッパーなど) と、それが前提の鉄のドアなど
- マルチプレイは専用サーバーではなく、ホストのブラウザを使う方式 (最大人数の制限はありませんが、4〜5 人程度を想定)
- ネザーとジ・エンドのディメンション、村人と交易、エンチャント、醸造、農業 (耕地と作物の成長)、釣り
- 銅の酸化の段階、キャンドル、看板、旗、シュルカーボックス、ボートやトロッコなどの乗り物
- 作業台の 3×3 グリッド (レシピ一覧から選ぶ方式で代用)

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
npm run preview  # ビルド結果を確認
```

## デプロイ

`.github/workflows/deploy.yml` が以下を自動で行います。

1. すべてのブランチ・Pull Request で `npm ci && npm run build` を実行してビルドを検証
2. `main` ブランチへの push 時のみ、`dist/` を `gh-pages` ブランチへ push して GitHub Pages で公開

`gh-pages` ブランチが作られると GitHub Pages が自動で有効になります。もし公開されない場合は、リポジトリの **Settings → Pages → Build and deployment → Source** を **Deploy from a branch**、Branch を **gh-pages** / **/(root)** に設定してください。

## 構成

```
index.html          画面・メニュー
src/main.js         起動、入力 (Minecraft 準拠)、採掘・設置・攻撃・食事、セーブ、昼夜、メインループ
src/world.js        地形生成 (洞窟・鉱脈)、チャンクのメッシュ化 (面カリング・AO・頂点ライト)、たいまつモデル
src/lighting.js     空の光と光源の光の伝播 (Minecraft 方式)
src/textures.js     手続き的なテクスチャの登録とアトラス生成
src/blocks.js       ブロックのカタログ (形・硬さ・適正道具・ドロップ・光・機能)
src/shapes.js       ハーフブロック・階段・ドア・フェンスなどの形 (描画・当たり判定・選択枠)
src/items.js        アイテム・道具・防具・食料の定義、ドット絵、タグ、レシピ、クリエイティブのタブ
src/icons.js        アイテムのアイコン (ブロックは立体、その他はドット絵)
src/inventory.js    持ち物 (36 スロット + 防具 4) とスタック操作、耐久値、燃料、クラフト
src/ui.js           インベントリ / クラフト / クリエイティブ / チェスト画面
src/hud.js          体力・満腹度・ホットバーなどの HUD
src/player.js       プレイヤー: 移動・スニーク・ダッシュ・飛行・体力・満腹度・落下ダメージ
src/physics.js      AABB の移動と衝突 (プレイヤー・モブ・アイテム共通)
src/mobs.js         動物と敵の AI・スポーン・矢・爆発
src/models.js       ブロック風のモブ / プレイヤーモデル
src/drops.js        落ちているアイテムと拾得
src/multiplayer.js  マルチプレイ (PeerJS / WebRTC。ホストが世界を管理し、参加者と同期)
src/hand.js         画面手前に描く一人称の腕と持ち物 (振り・持ち替えアニメーション)
src/touch.js        タブレット向けタッチ操作 (仮想ジョイスティック・ボタン)
src/raycast.js      視線が当たるブロックを求めるボクセル DDA
src/noise.js        シード付き乱数、2D パーリンノイズ
```
